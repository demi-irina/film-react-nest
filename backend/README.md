# FILM! — бэкенд

API афиши кинотеатра на NestJS. Отвечает за фильмы, расписание сеансов и бронирование мест.

## Стек

NestJS, TypeScript, TypeORM (PostgreSQL) и Mongoose (MongoDB), Jest.

## Настройка

```bash
npm ci
cp .env.example .env
```

Переменные окружения:

| Переменная        | Назначение                                    |
|-------------------|-----------------------------------------------|
| `DATABASE_DRIVER` | Драйвер базы данных: `postgres` или `mongodb` |
| `DATABASE_URL`    | Строка подключения к выбранной СУБД           |
| `LOGGER`          | Формат логов: `dev`, `json` или `tskv`        |
| `PORT`            | Порт HTTP-сервера, по умолчанию `3000`        |

## Команды

| Команда              | Назначение                     |
|----------------------|--------------------------------|
| `npm run start:dev`  | Запустить режим разработки     |
| `npm run build`      | Собрать приложение             |
| `npm run start:prod` | Запустить собранное приложение |
| `npm test`           | Запустить юнит-тесты           |
| `npm run test:cov`   | Запустить тесты с покрытием    |
| `npm run test:e2e`   | Запустить e2e-тесты            |
| `npm run lint`       | Проверить код линтером         |
| `npm run lint:fix`   | Исправить ошибки линтера       |
